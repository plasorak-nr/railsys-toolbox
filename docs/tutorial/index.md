# Tutorial

In this tutorial, you are going to use the Midlands Rail Hub project data, which contains a base case and five options. You are encouraged to use data from your own project as long as you have run it through `EvalManager`.

We will investigate:

- The worst stations in terms of punctuality,
- Some train-level punctuality, median lateness, and SRT data to identify the trains that contribute most to these delays,
- Whether these delays are caused by other trains,
- And, maybe, flighting problems.

## What you will need

- Access to this repo
- uv/python
- VS Code
